What the board can do, checked

Checked against the ESPHome 2026.8.2 image the panel already runs, which pulls LVGL 9.5.0, and against the live services in the house. Waveshare's product page refused an automated fetch, so the style follows the demo screenshots from that page.

In LVGL today

This look

Radius, opacity, gradients, shadows, background images, switch, slider, img, tileview, animations — all exposed by ESPHome's lvgl.

Pre-blur it

The room photo

LVGL 9.5 can blur live (blur_backdrop), but with no GPU that recomputes on every redraw. The photo is blurred once and stored; cards are drawn slightly translucent over it.

Dimmers too

Lights

Kitchen light switch and Family room switch are HS220 dimmers, so they get slider cards; the other four get toggle cards.

Snapshots, not video

Cameras

The risk that decides the order

The display is an RGB panel with no memory of its own: the ESP32-S3 streams 480×480 pixels out of its 8 MB PSRAM continuously, and the wake-word model uses that same PSRAM. Translucent cards over a photo add blending on every redraw. So the screen comes up static first, the wake word is measured with it running, and effects are added only while it stays healthy. If it degrades, the fallback is the same layout on a solid dark background. Cameras are last because a JPEG decode is the biggest memory spike.

Build order

  1. Display on, voice re-measuredBring up the RGB panel and touch with one static screen and the pre-blurred background. Repeat the wake-word checks; if detection or audio degrades, lower the refresh or drop the photo before adding anything.
  2. Home: lights and thermostatFour toggle cards, two dimmer sliders, the ecobee card, and the full-screen page per light — all bound to Home Assistant states, so voice, dashboard and panel always agree.
  3. ScenesAll on, all off and Movie mode as Home Assistant scripts, so "Okay Nabu, movie mode" and the dashboard run the same ones.
  4. SecurityThe six sensors the dashboard's alarm card already watches, plus the alarm state, read-only.
  5. Wall panel remoteA "show view" event on the dashboard's existing event stream, sent by a Home Assistant action, obeyed only by the hallway panel's browser.
  6. CamerasFront door and garage as separate 480-wide snapshots every 2 s, only while the screen is open.
  7. Sleep and wakeDim after a minute idle, wake on touch; "Okay Nabu" shows a listening overlay on whatever screen is up.

Decisions

Movie modeDecidedLiving room switch 2 off, Living room cabinet LED off, Living room ambient light on.
Light cardsDecidedThe six lights on the dashboard's Lights card, including Stick S3. Plugs are not on the panel.
Wall-panel viewsDecidedHome, Cameras, Security, Devices, Climate and Status. Only the hallway panel follows them, never a phone or the PC.
Camera refreshDecidedEvery 2 s while the Cameras screen is open, nothing otherwise.
